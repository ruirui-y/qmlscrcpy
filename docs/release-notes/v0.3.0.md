# QmlScrcpy 0.3.0

这一版加了**按键映射**和**连点器**，另外修了滚轮翻页过头的毛病。

## 新增：按键映射

给手游用键盘操作。侧边栏一个按钮循环三态：

```
映射 关  →  映射 玩  →  映射 编  →  关
```

- **关**：键盘照旧转发，打字不受影响（默认）
- **玩**：已映射的键走触摸，没映射的键照旧
- **编**：进入编辑模式，画面叠加可拖动的键位

### 三种键位

| 类型 | 用途 | 行为 |
|---|---|---|
| 点按 | 技能、平A | 按下后 40ms 抬起 |
| 按住 | 蓄力、持续开火 | 按住保持，松开才抬 |
| 摇杆 | 走位 | 按中心落指，W/A/S/D 推方向，松手回中 |

### 编辑方式

- **加点**：左下角填键名、选类型、点「添加」，圆点出现在画面中心
- **调位置**：拖动圆点，松手自动保存
- **重绑按键**：左键点圆点 → 顶部提示「请按下要绑定的键…」→ 按一下键盘即可
- **删除**：右键点圆点
- **改摇杆键**：左键点摇杆圆点（◎），右下角弹出四个方向键的输入框

每个设备一套配置，存在 `config/keymap/<串号>.json`，坐标是归一化的，换分辨率不用改。

### 技术要点

映射的按下状态**不订阅 Qt 的按键事件，改成每 16ms 轮询 `GetAsyncKeyState`**。

原因是 Windows 的键盘自动重复不可靠：`isAutoRepeat()` 会报 false，自动重复还会成对发 Press/Release。前五版都在“过滤事件”上失败，轮询硬件状态是唯一确定的做法，代价是松手最多晚 16ms。

排查全过程写在 [按键映射](按键映射.md)。

## 新增：连点器

侧边栏一个按钮，只有开关两态：

```
连点 关  ⇄  连点 50
```

开启后**按住空格**，在鼠标所在位置每 50ms 点一次，松开即停。抢票、抢购用。

位置在每次点击时用全局光标现查，鼠标不在画面上就不点。

## 修复

| 问题 | 原因 |
|---|---|
| 滚轮翻页过头（一格翻好几页） | 「滑动」模式下三条触摸消息在 0ms 内发完，安卓判定为极快甩动并惯性滚动。改成移动后停 120ms 再抬手，速度归零就不甩动了 |
| 拖动倍率拖不动圆点 | 圆点位置写成绑定，拖动赋值被绑定覆盖 |
| 编辑模式看不到已有键位 | 建 delegate 时叠加层宽度还是 0，坐标算到画面外 |
| Space 键映射无效 | 配置里存小写 `space`，虚拟键码表是大写，查表失败 |

## 已知限制

- 按键录制时按 Esc 不会取消（还没做）
- 新建摇杆固定 W/A/S/D，加完之后才能改
- 没有按游戏包名自动切换配置
- 连点只有 50ms 一档

## 升级说明

覆盖安装即可，配置保留。新增 `[input]` 下的 `click_interval`，以及 `config/keymap/` 目录。
