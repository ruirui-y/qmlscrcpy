# QmlScrcpy 0.1.4

这版主要是**卡顿修复**和**后台线程整理**，外加把「目录」按钮改成更实际的「文件首页」。

## 修复

### 拖动、缩放结束后会卡一下

拖动本身是跟手的，但**松手约 0.7 秒后会顿一下**——那一下是在写 `window.ini`：位置和尺寸保存走的是 `QSettings`，落盘是同步的，写文件期间 GUI 线程被挡住。

现在所有配置写盘都挪到**后台任务线程**，主线程只负责把值丢过去。

顺带解决一个隐患：主线程和后台线程各开一个 `QSettings` 写同一个 `window.ini` 时，主线程缓存里的旧值可能在退出时覆盖后台写的新尺寸。现在窗口配置只在任务线程里写。

### 侧边栏拖不动窗口

给工具栏加滚动（`Flickable`）之后，它默认 `interactive: true`，把鼠标按下事件全吃了，下面负责拖动窗口的 `MouseArea` 收不到事件。

改成 `interactive: false`，滚动改由 `MouseArea.onWheel` 处理——**拖动和滚动各归各的**。

## 改进

### 「目录」→「文件首页」

原来的「目录」按钮打开的是 AOSP 自带的文档界面（`com.android.documentsui`），有两个问题：

1. 它不是手机上的「文件管理」，界面完全不一样
2. 它的「下载」根目录只列 DownloadManager 记录，**adb 推上去的文件它看不到**，点进去显示"无任何文件"

现在优先拉起厂商文件管理（OPPO/realme/一加、小米、华为/荣耀、三星各试一遍），都拉不起来才退回 AOSP 界面。

按钮改名叫「文件首页」——因为厂商文件管理**不支持深链到子目录**（`file_path` / `path` / 目录 URI 都试过，只会停在首页），叫「目录」会让人以为能直达。

### 状态栏用中文目录名

`/sdcard/Download/QmlScrcpy` 这种路径直接显示不好读，现在统一换成手机上看到的叫法：

| 场景 | 提示 |
|---|---|
| 打开文件管理 | 已打开文件管理首页，文件在「下载/QmlScrcpy」 |
| 传输中 | 正在传 2 个文件到「下载/QmlScrcpy」… |
| 传输完成 | 2 个文件已传到「下载/QmlScrcpy」 |

## 内部重构

新增 `qsc::base::TaskRunner`：一条常驻线程 + 一条队列，`Post(std::function<void()>)` 投递。原来三处"谁要异步谁自己 `QThread::create`"（adb push、切无线、写配置）全部改成投递，退出时统一 `ShutdownTaskRunner()`。

线程模型现在是四条：GUI、渲染、视频读、后台任务。

## 下载与安装

下载 **`QmlScrcpy_Setup_0.1.4.exe`**，双击安装。

- 默认装到 `D:\QmlScrcpy`（**不要装 Program Files**：程序要往自己目录写 `config\`、`Log\`、`screenshots\`）
- 自带 Qt 运行库和 `adb.exe`，装完即用
- 升级安装会保留 `config\` 里的设置
- 没有代码签名，Windows 提示"未知发布者"时点「更多信息 → 仍要运行」

## 已知限制

| 限制 | 说明 |
|---|---|
| 文件管理只能停在首页 | 厂商 App 不支持深链到子目录，自己点 设备存储 → Download → QmlScrcpy |
| 键盘不能打中文 | 只发按键码；用剪贴板或手机输入法 |
| 文件传输只有电脑→手机 | 反向、文件夹暂不支持 |
| 没有"旋转设备"按钮 | scrcpy 的旋转注入依赖隐藏 API，Android 15 会拦掉 |
