# QmlScrcpy 0.1.2

这次三块：**文件拖拽传输**、**补齐常用按键和快捷键**、**主窗收成一个「设置」入口**。

## 新增

### 文件拖拽传输

把文件直接拖进投屏窗，松手就传到手机：

- 默认落在 `/sdcard/Download/QmlScrcpy/`，目录可在设置里改
- 状态栏显示实时进度（`传 文件名：45%`）
- **支持中文文件名**：绕开了 adb 在 Windows 上把中文名吞成空串的问题
- 多选文件会逐个传

### 桌面 / 电源按键

工具栏新增两个按钮：

| 按钮 | 作用 |
|---|---|
| 桌面 | 回手机桌面（`KEYCODE_HOME`） |
| 电源 | 按一下手机电源键，锁屏或点亮（`KEYCODE_POWER`） |

顺带说明三者的区别：「息屏」只关屏幕显示、不锁屏；「电源」才等于按手机电源键。

### 快捷键

| 组合 | 动作 |
|---|---|
| `Esc` | 返回 |
| `Home` | 回桌面 |
| `Ctrl+Shift+S` | 截图 |
| `F11` | 全屏 / 还原 |
| `Ctrl+Alt+B` | 老板键（全局热键） |

全部可以在设置里改，留空即禁用。

### 主窗收成「设置」

原来主窗右上角排了四个按钮（画质 / 重置 / 老板键 / 命令行），加上快捷键就没地方了。现在合成一个「设置」，里面三组：

- **画质**：帧率、码率，改完自动重连
- **快捷键**：返回 / 回桌面 / 截图 / 全屏 / 老板键
- **其他**：文件上传目录、命令行开关、恢复默认配置

## 修复

| 问题 | 原因 |
|---|---|
| 拖进来的文件提示"不是文件" | QML 的 `drop.urls` 用 `QVariantList` 接会整张表变成一个 variant，改成 `QList<QUrl>` |
| 中文名文件（mp4/md）传不上去 | adb.exe 在 Windows 上按 ANSI 解释参数，中文名被吞成空串；改成 ASCII 临时名推送 + base64 在设备上改回原名 |
| 设置窗关不掉 | 标题栏拖动区声明在关闭按钮之后，盖住了按钮；把拖动区挪到最前面，另加 `Esc` 关闭 |
| 按老板键藏不掉设置窗 | 设置窗没登记进老板键的窗口名单 |

## 下载与安装

下载 **`QmlScrcpy_Setup_0.1.2.exe`**，双击安装。

- 默认装到 `D:\QmlScrcpy`（**不要装 Program Files**：程序要往自己目录写 `config\`、`Log\`、`screenshots\`）
- 自带 Qt 运行库和 `adb.exe`，装完即用
- 没有代码签名，Windows 提示"未知发布者"时点「更多信息 → 仍要运行」

## 已知限制

| 限制 | 说明 |
|---|---|
| 键盘不能打中文 | 只发按键码；用剪贴板或手机输入法 |
| 文件传输只有电脑→手机 | 反向、文件夹暂不支持 |
| 没有"旋转设备"按钮 | scrcpy 的旋转注入依赖隐藏 API，Android 15 会拦掉 |
| 小米 / 红米点击无反应 | 要在开发者选项里额外打开「USB 调试（安全设置）」 |
