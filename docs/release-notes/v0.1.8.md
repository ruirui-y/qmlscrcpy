# QmlScrcpy 0.1.8

修一个自动更新的硬伤：**下载地址用错了**。

## 修复

### 「立即更新」会把网页当安装包装

`latest.json` 里原本只有一个 `url`，存的是 Gitee 的 **releases 页面**。自动更新直接拿它去 `curl`，下回来的是 HTML，然后哈希校验必然失败。

现在拆成两个字段：

| 字段 | 内容 |
|---|---|
| `url` | 下载页面，给浏览器用 |
| `exe` | **exe 直链**，给 curl 用 |

`latest.json` 里没有 `exe` 时，按钮自动退回「去下载」，不会瞎装。

### 发版脚本自动补字段

`setup/release_gitee.ps1` 现在会写 `exe` / `size` / `sha256` 三个值，发版不用手填。

## 怎么测

0.1.7 有这个 bug，用它测不出来。请装 **0.1.8**，然后按 [docs/自动更新.md](https://github.com/ruirui-y/qmlscrcpy/blob/master/docs/自动更新.md) 第 9 节用本地 JSON 模拟"发现 0.1.9"来验证下载 → 校验 → 安装 → 重启。
