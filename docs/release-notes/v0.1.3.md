# QmlScrcpy 0.1.3

这版全是体验修复：**横屏尺寸**、**侧边栏遮挡**、**关窗后的状态**，另外加了「一键打开传输目录」。

## 修复

### 第一次进横屏窗口太大

竖屏用着、手机转横屏时，窗口会被撑到接近全屏，得手动点一次「复位」。

原因：横屏尺寸有两条代码路径（第一帧就是横屏 / 先竖屏后转横屏），只有第一条有 900×400 的默认值。

顺带解决了一个更隐蔽的问题：老配置里存着按旧算法算出来的尺寸，光改代码看不到效果。这次做了**一次性迁移**，老用户升级后自动清掉旧记录，之后自己拖出来的尺寸不会再被抹掉。

### 侧边栏第一个按钮被提示条挡住

鼠标划过工具栏按钮时，标题栏那条悬停说明会横跨整个窗口，压住工具栏最上面的「返回」。

工具栏整体下移 34px，并且**改成可滚动**——横屏窗口只有 400 高，16 个按钮约 580px，以前「全屏」「复位」其实点不到。

### 关掉投屏窗后主窗还显示"已连接"

点投屏窗的 ✕ 只是把窗口藏起来，会话没断。而「连接」按钮对已连接的会话不会再触发状态变化，投屏窗就再也叫不回来——必须先点「断开」再点「连接」。

现在 **关窗 = 断开**：✕ 和 `Alt+F4` 都会先断开连接，主窗立刻变成「未连接」，再点「连接」直接就能用。

### 设置窗开着时不能拖文件

设置窗原来是模态（`ApplicationModal`），模态窗口会挡掉其它窗口的拖放事件。改成非模态，设置开着也能往投屏窗拖文件。

## 新增

### 一键打开传输目录

工具栏新增「目录」按钮（设置窗里也有「打开目录」）：点一下，手机自动弹出文件管理器，直接看传到 `Download/QmlScrcpy` 的文件。

传完文件不用再去翻「文件管理」，也不用走文件传输助手。

## 下载与安装

下载 **`QmlScrcpy_Setup_0.1.3.exe`**，双击安装。

- 默认装到 `D:\QmlScrcpy`（**不要装 Program Files**：程序要往自己目录写 `config\`、`Log\`、`screenshots\`）
- 自带 Qt 运行库和 `adb.exe`，装完即用
- 升级安装会保留 `config\` 里的设置
- 没有代码签名，Windows 提示"未知发布者"时点「更多信息 → 仍要运行」

## 已知限制

| 限制 | 说明 |
|---|---|
| 键盘不能打中文 | 只发按键码；用剪贴板或手机输入法 |
| 文件传输只有电脑→手机 | 反向、文件夹暂不支持 |
| 打开目录可能停在「下载」根目录 | 部分机型不认子目录 URI，`QmlScrcpy` 文件夹就在第一项 |
| 没有"旋转设备"按钮 | scrcpy 的旋转注入依赖隐藏 API，Android 15 会拦掉 |
