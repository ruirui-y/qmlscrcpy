# QmlScrcpy 0.2.0

这版加了两组输入手感设置：**拖拽倍率**解决"小幅拖动翻不了页"，**捏合缩放**解决"图片和地图没法放大"。

## 新增

### 拖拽倍率

鼠标拖动画面的位移可以放大，用来应付需要"划够距离才触发"的界面：

```
鼠标拖 100 像素 × 1.5 = 设备上的手指走 150 像素
```

- 侧边栏 `−` / `+` 调整，一次 0.1
- 范围 1.0 ~ 3.0，默认 1.0（和以前完全一致）
- 当前值显示在按钮下方：`拖拽 1.5x`，大于 1.0 时变蓝
- 立即生效，不用重连；写进 `window.ini` 的 `[input] drag_scale`

建议值：短视频/长列表用 1.5~2.0，精确选文字用 1.0。

### 捏合缩放（修饰键 + 滚轮）

按住修饰键再滚轮，等于两根手指在屏幕上捏合：

| 项 | 值 |
|---|---|
| 默认修饰键 | Ctrl |
| 方向 | 上滚放大、下滚缩小 |
| 每格 | 15% |
| 缩放中心 | 鼠标位置 |
| 结束 | 松开修饰键立即结束 |

修饰键点一下循环切换：`Ctrl → Alt → Shift → Ctrl+Alt → 关`，按钮上用缩写显示（`捏合 C` / `A` / `S` / `C+A`）。

捏合进行中按钮后面会出现一个圆点（`捏合 C ●`）并高亮——松手后圆点还在，说明设备那边还按着手指。

## 修复

| 问题 | 原因 |
|---|---|
| 捏合"缩几下就缩不动" | 第二根手指用了 `ACTION_DOWN`，设备把它当成新手势，打断了正在进行的捏合。改成 `ACTION_POINTER_DOWN` / `ACTION_POINTER_UP` |
| 松开 Ctrl 后必须动一下鼠标才恢复 | Qt 的 `keyboardModifiers()` 靠事件更新，没有新事件时读到的是旧值。改用 `GetAsyncKeyState` 直接问系统 |
| 慢速滚轮每一格都从初始大小开始 | 手势被超时切成多次。取消定时器，改成松手即结束，半径跨手势保留 |
| 捏合提示文字被截断 | 文案缩短为一行能放下的长度 |

## 其他

- 删掉排查期遗留的 UpdateRequest 探针（`eventFilter`、`update_request_us_` 等只写不读的代码）
- 删掉两个只声明没实现的方法
- 文档里过时的 `QS_PERF` 统一改成 `QS_TRACE_FRAMES`

## 升级说明

覆盖安装即可，配置保留。新增的两个键会自动写进 `window.ini` 的 `[input]`，默认值就是旧版行为。
