# QmlScrcpy 0.1.5

**增加版本检查**：启动时自动检查更新，有新版就在主窗右上角亮红标；安装包同步迁到 Gitee 发布。

## 新增

### 自动检查更新（不需要服务器）

启动时读一个静态 `latest.json`，比一下版本号：

- 有新版本 → 主窗右上角橙色「新版 0.1.5」，鼠标悬停显示改了什么，点一下打开下载页
- 版本低于最低支持版本 → 红色「必须更新 0.1.5」
- 版本一致 / 网络不通 → 什么都不显示

检查走三个源依次尝试：**Gitee → jsDelivr → GitHub**，谁先返回合法 JSON 用谁。全部失败只写一行日志，**不影响正常使用**。

版本号在编译期就写进二进制（`QS_APP_VERSION`），不联网也知道自己是谁。比较规则按数字来，`0.10 > 0.9`，远端给错格式时不会把用户误拦在旧版本。

```
https://gitee.com/bai-maxifeng/qmlscrcpy/releases
```

原因：GitHub Releases 国内下载经常连不上，45MB 的包等半天。Gitee 免费、国内可直连。

- **代码和 issue 仍在 GitHub**
- **安装包和版本发布在 Gitee**
- 客户端读的 `latest.json` 也挂在 Gitee 上

GitHub 上的 Release 只有说明文字，不再附 exe。

## 下载与安装

在 [Gitee Releases](https://gitee.com/bai-maxifeng/qmlscrcpy/releases) 下载 `QmlScrcpy_Setup_0.1.5.exe`。

- 默认装到 `D:\QmlScrcpy`（**不要装 Program Files**：程序要往自己目录写 `config\`、`Log\`、`screenshots\`）
- 自带 Qt 运行库和 `adb.exe`，装完即用
- 升级安装保留 `config\` 里的设置
- 没有代码签名，Windows 提示"未知发布者"时点「更多信息 → 仍要运行」

## 已知限制

| 限制 | 说明 |
|---|---|
| 检查更新可能无提示 | 三个源都不通时静默跳过，属于预期行为 |
| 文件管理只能停在首页 | 厂商 App 不支持深链到子目录 |
| 键盘不能打中文 | 只发按键码；用剪贴板或手机输入法 |
| 文件传输只有电脑→手机 | 反向、文件夹暂不支持 |
| 没有"旋转设备"按钮 | scrcpy 的旋转注入依赖隐藏 API，Android 15 会拦掉 |
