# v0.4.1

发布 2026-11-23

修 0.4.0 里两个问题：画面发灰，以及上屏延迟还有一截没榨干。

## 修了什么

### 画面发灰、对比度被压平（0.4.0 引入）

0.4.0 换了新的转色着色器，抄系数时漏了 `1.164` —— 有限范围（16~235）拉回全范围的那个关键系数。

```
错：rgb = Y - 0.0625 + 色度项            ← 对比度被压平，画面发闷
对：rgb = (Y - 0.0625) × 1.164 + 色度项  ← 和 0.3.1 的着色器一致
```

这一版改回来了，颜色和 0.3.1 一致。

### 上屏延迟又降了约 1 ms

0.4.0 里渲染线程每帧有 1.25 ms 卡在「等解码图层写完」。这次把这个等待挪到解码线程
（它每帧只用 0.5 ms，余量大），渲染线程拿到的帧已经是写完的。

| 指标 | 0.4.0 | 0.4.1 |
|---|---|---|
| 渲染线程绘制（含转色） | 1.57~1.73 ms | **0.27~0.35 ms** |
| 上屏延迟中位 | 2.5~3.5 ms | **1.5~2.5 ms** |
| 上屏延迟最大 | 3.0~3.9 ms | **2.3 ms** |

参考：同一台机器、1264×2780，实测 `1s 到达 120 帧，上屏 120 帧，丢 0`。

### 顺带修的

- 逐帧追踪在零拷贝路径上之前是断的（埋点漏了一次赋值），现在 `QS_TRACE_FRAMES=1` 能看到每帧明细
- `adb` 找不到的问题：程序目录没有 `Tools\adb.exe` 时会回落到 PATH 里的 adb（文档一直这么写，代码没实现）
- 三个长期红着的单测（adb / server_args / input）修好了，`ctest` 现在 11 个全过
- scrcpy-server 版本号在文档里从 3.3.3 更正为 5.0.1

## 已知问题

- 硬解只支持 D3D12，驱动不支持的机器会退软解
- 安装包 47.7 MB，比 0.3.1 的 36.1 MB 大，主要是 FFmpeg 8.1 的解码器本体变大

## 升级注意

- 从 0.4.0 升上来直接覆盖装即可，配置不用改
- 从 0.3.1 及更早升上来，首次启动会自动把 `window.ini` 里的设置迁到 `config.ini`，日志里有 `[app] 配置已迁移`
