# QmlScrcpy 0.1.6

**这个版本只用来验证"自动检查更新"这条链路**：exe 里除了版本号没有任何改动。

## 目的

装 0.1.5 的人，打开 0.1.6 的客户端后：

1. 程序启动 → 主窗右上角出现橙色「新版 0.1.6」
2. 鼠标悬停 → 显示这条备注
3. 点一下 → 浏览器打开 Gitee 的下载页

用来确认「Gitee 上的 latest.json → 客户端解析 → 比对 → 红标 → 跳转下载」整条路是通的。

## 为什么单独发一版

版本检查没法在一台机器上自证——必须有"旧版本客户端 + 新版本元数据"这两个东西同时存在。所以发一个只改版本号的包，装 0.1.5 看它能不能提示。

## 下载

在 [Gitee Releases](https://gitee.com/bai-maxifeng/qmlscrcpy/releases) 下载 `QmlScrcpy_Setup_0.1.6.exe`。

装好之后如果主窗没有红标，说明检查没成功，看日志里这三行之一：

```
[update] 没找到 OpenSSL，改用 curl.exe 检查
[update] 本地 "0.1.5" 远端 "0.1.6" 提示更新 true 强制 false
[update] 所有源都不可用（不影响使用）
```
