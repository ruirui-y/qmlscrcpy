# QmlScrcpy 0.1.0

首个可用版本：有线 / 无线投屏、输入注入、画质可调。

## 下载与安装

下载 **`QmlScrcpy_Setup_0.1.0.exe`**，双击安装。

- 默认装到 `D:\QmlScrcpy`（**不要改装 Program Files**：程序要往自己目录写 `config\`、`Log\`、`screenshots\`，那里没有写权限）
- 自带 Qt 运行库和 `adb.exe`，装完即用，不需要额外准备环境
- 安装包没有代码签名，Windows 提示"未知发布者"时点「更多信息 → 仍要运行」

## 这个版本能做什么

- **有线 / 无线投屏**：自适应 120Hz 屏幕，无线第一次要插线切一次
- **输入**：鼠标点击、长按、拖动、滚轮（两种模式）、键盘（含 `Shift + ?` 这类符号）
- **工具栏**：返回、任务、滚轮模式、滑动像素 ±5/±1、音量、截图（同时进剪贴板）、息屏/亮屏、置顶、全屏、复位
- **画质可调**：帧率与码率自己填，有线和无线各存一套；改完自动重连
- **启动行为**：只显示主窗，连上设备后投屏窗才出现；自动连上次用过的设备
- **窗口**：横竖屏各记一套尺寸和位置，拖标题栏或工具栏空地都能移动

## 已知限制

| 限制 | 说明 |
|---|---|
| 中文输入不支持 | 只发安卓按键码，中文请用手机输入法打 |
| 没有"旋转设备"按钮 | scrcpy 的旋转注入依赖隐藏 API，Android 15 会拦掉，且不报错 |
| 小米 / 红米点击无反应 | 需要在开发者选项里额外打开「USB 调试（安全设置）」 |
| 无代码签名 | SmartScreen 会提示"未知发布者" |
