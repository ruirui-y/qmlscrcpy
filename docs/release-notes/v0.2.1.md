# QmlScrcpy 0.2.1

这一版加了**按键映射**和**连点器**，并修了滚轮翻页过头的毛病。

## 新增：按键映射

侧边栏一个按钮循环三态：

```
映射 关  →  映射 玩  →  映射 编  →  关
```

- **关**：键盘照旧转发，打字不受影响（默认）
- **玩**：已映射的键走触摸，没映射的键照旧
- **编**：编辑模式，画面上显示可拖动的键位圆点

### 三种键位

| 类型 | 用途 | 行为 |
|---|---|---|
| 点按 | 技能、平A | 按下后 40ms 抬起 |
| 按住 | 蓄力、持续开火 | 按住保持，松开才抬 |
| 摇杆 | 走位 | 按中心落指，W/A/S/D 推方向，松手回中 |

### 编辑方式

- **加点**：左下角填键名、选类型、点「添加」
- **调位置**：拖动圆点，松手自动保存
- **重绑按键**：左键点圆点 → 顶部提示「请按下要绑定的键…」→ 按一下键盘
- **删除**：右键点圆点
- **改摇杆键**：左键点摇杆圆点（◎），右下角填四个方向键

每台设备一套配置，存在 `config/keymap/<串号>.json`，坐标归一化，换分辨率不用改。

### 为什么用轮询而不是按键事件

Windows 的键盘自动重复不可靠：`isAutoRepeat()` 会报 false，自动重复还会成对发 Press/Release。前五版都在“过滤事件”上失败，最后改成每 16ms 轮询 `GetAsyncKeyState`，只认硬件状态，代价是松手最多晚 16ms。

排查全过程见 `docs/按键映射.md`。

## 新增：连点器

侧边栏一个按钮，只有开关两态：

```
连点 关  ⇄  连点 50
```

开启后**按住空格**，在鼠标所在位置每 50ms 点一次，松开即停。

位置在每次点击时用全局光标现查，鼠标不在画面上就不点。

## 修复

| 问题 | 原因 |
|---|---|
| 滚轮翻页过头（一格翻好几页） | 「滑动」模式下三条触摸消息在 0ms 内发完，安卓判定为极快甩动并惯性滚动。改成移动后停 120ms 再抬手，速度归零就不甩动 |
| 圆点拖不动 | 位置写成绑定，拖动赋值被绑定覆盖 |
| 编辑模式看不到已有键位 | 建 delegate 时叠加层宽度还是 0，坐标算到画面外 |
| Space 键映射无效 | 配置里存小写 `space`，虚拟键码表是大写，查表失败 |

## 已知限制

- 录制按键时按 Esc 不会取消
- 新建摇杆固定 W/A/S/D，加完才能改
- 没有按游戏包名自动切换配置
- 连点固定 50ms 一档

## 升级说明

覆盖安装即可，配置保留。新增 `[input]` 下的 `click_interval` 和 `config/keymap/` 目录。
