# QmlScrcpy 0.1.7

**一键更新**：发现新版本后不用再自己开浏览器下载，程序自己下、自己校验、自己装。

## 新增

### 一键更新

主窗右上角的红标点开是一个面板：

```
发现新版本 0.1.7
这次改了什么…
[████████░░░░]  正在下载 0.1.7…
[立即更新]  [下载页]  [稍后]
```

点「立即更新」之后：

1. 用系统 `curl` 把安装包拉到 `%TEMP%\QmlScrcpy\`
2. 核对字节数 + **SHA-256**（不一致就删掉，绝不安装坏包）
3. 启动安装程序 `/SILENT /CLOSEAPPLICATIONS`，程序自己退出
4. 装完自动启动新版本

进度条按文件大小算，随时可以取消。

### 失败有退路

| 情况 | 表现 |
|---|---|
| 下载失败 / 断网 | 状态栏说明原因，半截文件自动删掉 |
| 哈希不匹配 | 提示"校验失败，已删除安装包" |
| 远端没给 sha256 | 按钮变成「去下载」，开浏览器手动下 |
| 安装程序起不来 | 提示去下载页手动安装 |

**「下载页」和「稍后」永远都在**——不把用户堵在一个不动的进度条上。

## 需要注意

安装时**仍会弹一次 UAC**（要管理员权限装到 `D:\QmlScrcpy`）。这一步绕不过去，除非把安装位置改到用户目录。详细原因见 [docs/自动更新.md](https://github.com/ruirui-y/qmlscrcpy/blob/master/docs/自动更新.md)。

安全软件可能对"程序自己下载并执行 exe"报警，这属于这类功能的通病；介意的话用「下载页」手动装。

## 下载与安装

在 [Gitee Releases](https://gitee.com/bai-maxifeng/qmlscrcpy/releases) 下载 `QmlScrcpy_Setup_0.1.7.exe`。

- 默认装到 `D:\QmlScrcpy`（**不要装 Program Files**：程序要往自己目录写 `config\`、`Log\`、`screenshots\`）
- 自带 Qt 运行库和 `adb.exe`，装完即用
- 升级安装保留 `config\` 里的设置
- 没有代码签名，Windows 提示"未知发布者"时点「更多信息 → 仍要运行」

## 已知限制

| 限制 | 说明 |
|---|---|
| 安装时弹 UAC | `PrivilegesRequired=admin`，装到 D 盘必然要提权 |
| 不支持断点续传 | 中断后重下 45MB |
| 检查更新可能无提示 | 三个源都不通时静默跳过 |
| 键盘不能打中文 | 只发按键码；用剪贴板或手机输入法 |
| 文件传输只有电脑→手机 | 反向、文件夹暂不支持 |
