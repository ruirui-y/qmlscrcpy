# QmlScrcpy 0.1.1

这次加了两块功能：**电脑和手机互传文字**、**一键隐藏所有窗口的老板键**，另外修掉了 0.1.0 里两个"看起来能用其实没通"的 bug。

## 新增

### 剪贴板双向同步

工具栏新增两个按钮：

| 按钮 | 做什么 |
|---|---|
| **发给手机** | 电脑剪贴板里的文字写进手机剪贴板，并自动粘贴到当前输入框 |
| **取回电脑** | 读取手机剪贴板，写进电脑剪贴板 |

- 只支持纯文本，单次约 250 KB 上限
- **中文没问题**：这条路径传的是 UTF-8 文本，不是按键码。键盘打不出中文时，用手机复制、电脑粘贴（或反过来）就能绕过去
- 想要自动同步可以开 `config.ini` 的 `[input] clipboard_autosync=true`（默认关，避免把敏感内容推给手机）

### 老板键

按 `Ctrl+Alt+B` 一键藏起主窗和投屏窗（任务栏也看不到图标），再按一次原样恢复。

- 全局热键，窗口没有焦点时也有效
- 断开设备时自动恢复窗口，不会出现"程序在跑但找不到界面"
- **主窗右上角可以直接改**：点显示当前组合的按钮，输入新组合后点「应用」立即生效并记住（写 `window.ini`）
- 也支持手改 `config.ini` 的 `[ui] boss_key`，格式 `Ctrl+Shift+F9`、`Alt+Space` 这类写法
- 新组合被别的程序占用时，会自动保留原来的组合，不会把老板键弄丢

## 修复

| 问题 | 原因 |
|---|---|
| 「取回电脑」点了没反应（0.1.0 只有「发给手机」能用） | 设备消息类型号写错：scrcpy 是 `CLIPBOARD=0 / ACK_CLIPBOARD=1`，我们写成了 1/2/3，读路径从来没通 |
| 老板键只藏主窗，投屏窗闪一下又回来 | ① 投屏窗在 QML 里声明在主窗内部，不在 `topLevelWindows()` 里；② Qt 隐藏后会把渲染窗口再 `show()` 一次，需要补一刀 |

## 下载与安装

下载 **`QmlScrcpy_Setup_0.1.1.exe`**，双击安装。

- 默认装到 `D:\QmlScrcpy`（**不要装 Program Files**：程序要往自己目录写 `config\`、`Log\`、`screenshots\`）
- 自带 Qt 运行库和 `adb.exe`，装完即用
- 没有代码签名，Windows 提示"未知发布者"时点「更多信息 → 仍要运行」

## 已知限制

| 限制 | 说明 |
|---|---|
| 键盘不能打中文 | 只发安卓按键码；用剪贴板或手机输入法 |
| 没有"旋转设备"按钮 | scrcpy 的旋转注入依赖隐藏 API，Android 15 会拦掉 |
| 小米 / 红米点击无反应 | 要在开发者选项里额外打开「USB 调试（安全设置）」 |
| 无代码签名 | SmartScreen 会提示"未知发布者" |
