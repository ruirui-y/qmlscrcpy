# v0.4.0

发布 2026-11-23

这次是渲染栈整体换代：从 Qt5 时代的 OpenGL 画布换成 Qt6 的 RHI + D3D12，
解码也跟着换到 d3d12va，并且做到**解码纹理不出显存**。

## 你能感觉到的变化

### 画面更跟手

同一台手机、同样分辨率（1264×2780）、同一张动图对比：

| 版本 | 每秒到达 | 每秒上屏 |
|---|---|---|
| 0.3.1 | 106 | **76** |
| 0.4.0 | 113 | **110** |

上屏帧率从 76 涨到 110，掉帧基本消失（实测丢 0~1 帧）。

### 电脑更省

以前每一帧画面都要从显卡搬回内存、再从内存传回显卡，一趟 10.5 MB；
现在整段留在显存里做，**这一趟彻底省掉**：

```
0.3.1：每帧搬运 21.1 MB，其中 10.5 MB 走 PCIe
0.4.0：每帧搬运约 9.8 MB，PCIe 部分为 0
```

### 长按 CPU 的场景更稳

解码读回那 1.65~3.3 ms 没了，一帧的总开销从约 6.5~8.1 ms 降到约 1.9 ms。

## 其它改动

- **配置文件合并**：所有设置集中到 `config.ini`，`window.ini` 只存窗口位置和上次连接的设备。
  老用户的配置会在首次启动时自动迁移，不用手动改。
- **硬解只剩一条路**：d3d12va。起不来就退回软解，不再有中间那套 D3D11 读回。
- **设置里去掉「读回方式」**：零拷贝之后没有读回这一步，那选项改了也没用，删掉。

## 已知问题

- 硬解只支持 D3D12。显卡驱动不支持 D3D12 视频解码的机器会自动退软解，软解在原生分辨率下很吃力。
- 老配置文件里可能残留 `async_readback=0` 这行，程序不再读它，可以手动删掉。
- 首次启动会做一次配置迁移，日志里有一行 `[app] 配置已迁移`。

## 升级注意

- 直接覆盖安装即可，配置自动迁移，不需要重设画质和快捷键。
- 如果之前手动改过 `window.ini` 里的设置项，改完 0.4.0 之后这些值会被搬到 `config.ini`
  （`config.ini` 里已有同名项的以 `config.ini` 为准）。
- 装回旧版本会把 `config.ini` 的新结构当成未知项，画质设置要重设一次。
