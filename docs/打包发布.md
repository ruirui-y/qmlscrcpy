# 打包发布

用 **Inno Setup 6** 打成一个 Windows 安装包，双击安装即可运行，不需要装 Qt。

```
setup/
├─ collect.ps1          收发布文件：构建 Release → 拷进 stage → 清运行期产物 → 带上 adb
├─ QmlScrcpy.iss        Inno Setup 脚本
├─ build_installer.bat  调 ISCC 编译
├─ stage/QmlScrcpy/     收集好的发布目录（collect.ps1 生成，不入库）
└─ Output/              生成的安装包（不入库）
```

## 1. 这一阶段要做什么

把 `build\windows-release\bin\Release` 里那摊东西（exe + Qt 运行库 + plugins + scrcpy-server）做成一个安装包，用户拿到 `.exe` 双击就能装，装完桌面/开始菜单有快捷方式，不依赖开发机上的 Qt。

## 2. 怎么做的

两步：**先收集，再编译**。

```powershell
# ① 收发布文件（会先构建 Release）
powershell -ExecutionPolicy Bypass -File setup\collect.ps1

# ② 编译安装包
setup\build_installer.bat
```

`collect.ps1` 干这五件事：

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1~2 | `cmake --preset windows-release` + `cmake --build --preset build-windows-release` | 用 Release 构建（Debug 会带 `Qt5Cored.dll` 这一堆调试库，体积大、还依赖调试 CRT） |
| 3 | 清空 `setup\stage`，把 Release 产物整个拷进去 | stage 是安装包的唯一来源，避免打到旧文件 |
| 4 | 删掉 `Log/`、`screenshots/`、`config/`、`*.pdb` | 这些是跑起来才产生的；带上会把**我们自己的** `last_serial`、窗口位置打进安装包 |
| 5 | 找 `adb.exe`（`QS_ADB_PATH` → PATH），连同 `AdbWinApi.dll`/`AdbWinUsbApi.dll` 放进 `Tools\` | 用户装完不用再折腾 platform-tools |

## 前置：Inno Setup 6

```powershell
# 检查装没装（本机已装：C:\Program Files (x86)\Inno Setup 6\）
Test-Path "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe"
```

没装就下：<https://jrsoftware.org/isdl.php>，一路默认安装即可（`build_installer.bat` 会自动找 `Program Files (x86)` 和 `Program Files` 两个位置）。

## 产物目录是 RelWithDebInfo，不是 Release

`CMakePresets.json` 里 `windows-release` 这个 preset 的配置类型是 **RelWithDebInfo**：

```json
"configuration": "RelWithDebInfo"
```

所以产物在 `build\windows-release\bin\RelWithDebInfo\`，写死 `bin\Release` 会报"没找到 exe"。`collect.ps1` 里用 `Find-ReleaseDir()` 自动找：

```powershell
# 列出 bin 下所有含 QmlScrcpy.exe 的配置目录，按 RelWithDebInfo → Release → 其它 排序
$ordered = $found | Sort-Object { switch -Wildcard ($_) { '*RelWithDebInfo*' {0} '*Release*' {1} default {2} } }
```

跑起来会打印实际用的目录，方便确认打包的是哪份产物。

## 文件编码（第一次跑就踩了）

```
setup\collect.ps1         UTF-8 with BOM   ← Windows PowerShell 5.1 没 BOM 会按 GBK 读，中文把引号吃掉
setup\QmlScrcpy.iss       UTF-8 with BOM   ← Inno Setup 6 认 BOM 才正确解析中文
setup\build_installer.bat GBK              ← cmd 按系统 ANSI 读，UTF-8 会花屏
```

报错长这样（第 88 行的中文被拆开，报"字符串缺少终止符"）：

```
所在位置 setup\collect.ps1:88 字符: 13
+ Write-Host ("瀹屾垚锛?stageDir...
字符串缺少终止符: "。
```

以后改这三个文件，**存盘时确认编码没变**，否则又会挂。

## 3. 为什么第一版（直接打包 build 目录）不行

- **Debug 构建的 Qt 库带 `d` 后缀**（`Qt5Cored.dll`），还依赖 `msvcp140d.dll` 等调试 CRT，普通用户机器上根本没有
- **把 `config/`、`Log/`、`screenshots/` 打进去** → 安装包里带着开发机的 `last_serial`（上次连的设备 IP），用户装完会自动去连一台不存在的设备
- **装到 `Program Files` 会写不进配置**：程序要把 `config.ini` / `window.ini` / 日志写在 exe 旁边，`Program Files` 默认只读

所以：Release 构建 + 清运行期产物 + 默认装 `D:\QmlScrcpy`。

## 4. 怎么定位的

打包后第一次装完启动就白屏，`Log` 目录没有生成：

- 手动在安装目录下建 `config\` 能写 → 说明目录权限没问题，是别的地方
- 看安装路径是 `C:\Program Files\QmlScrcpy`，用普通用户启动，`QSettings::sync()` 静默失败
- 把 `DefaultDirName` 改成 `D:\QmlScrcpy`（`PrivilegesRequired=admin` 保证能建目录）后正常

另外一次是装完自动连了 `192.168.31.114:5555`——因为 stage 里带了 `config/window.ini`，`last_serial` 是开发机的。删掉 `config/` 后干净。

## 5. 怎么解决的

| 问题 | 解法 |
|---|---|
| Debug 库 | `collect.ps1` 固定用 `windows-release` preset |
| 带开发机配置 | 第 4 步删 `Log` / `screenshots` / `config` |
| 装进 Program Files 写不进配置 | `DefaultDirName=D:\QmlScrcpy`，且 `PrivilegesRequired=admin` |
| 用户没有 adb | stage 里带 `Tools\adb.exe`，程序查找顺序里加了 `Tools\` 子目录，装完直接能用 |
| 卸载后重装带上旧配置 | `[UninstallDelete]` 里显式删 `Log`、`screenshots`、`config` |

## 6. 最终效果与收获

```
setup/Output/QmlScrcpy_Setup_0.1.0.exe    ≈ 60~80 MB（Qt 运行库占大头）
安装到 D:\QmlScrcpy\
  ├─ QmlScrcpy.exe
  ├─ Qt5Core.dll / Qt5Quick.dll / ...
  ├─ platforms\qwindows.dll
  ├─ scrcpy-server
  ├─ Tools\adb.exe      ← 程序查找顺序：QS_ADB_PATH → 程序目录 → Tools\ → PATH
  └─ 首次启动后自动生成 config\、Log\
```

- 收获：**打包目录必须由脚本收集**，手动拷一次就会漏文件，下一次又忘
- 收获：**"能不能写自己目录"决定了安装位置**；凡是要在旁边写配置的程序，别装 Program Files
- 收获：**安装包要把开发机的状态清干净**（配置、日志、截图），否则用户第一次启动就是"接着别人的状态跑"

## 已知限制

- 安装包没有签名，Windows SmartScreen 会提示"未知发布者"
- 没有带图标资源（安装向导用的是 Inno Setup 默认图标），要的话准备 `.ico` 并加 `SetupIconFile`
