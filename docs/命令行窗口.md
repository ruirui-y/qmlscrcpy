# 命令行窗口开关

主窗右上角一个「命令行」按钮，控制那扇黑色控制台窗口显示还是隐藏，状态记在 `window.ini`，下次启动照上次的选择来。

## 为什么会有这扇控制台窗口

exe 的子系统由 CMake 选项决定：

```cmake
option(QS_HIDE_CONSOLE "去掉控制台窗口（发布版打开）" OFF)
```

- `QS_HIDE_CONSOLE=OFF`（当前调试配置）→ 子系统是 **Console(3)**，进程一启动就带一扇控制台，`qDebug` / `qInfo` 直接看得见
- `QS_HIDE_CONSOLE=ON` → 子系统是 **GUI(2)**，没有控制台，日志只进文件

调试时要看日志，发布时不想让用户看到黑窗口，所以做成运行时可切换。

## 怎么实现

`libs/base/console_window.*` 两个函数：

```cpp
bool ConsoleWindowAvailable();                 // 有没有控制台（GUI 子系统下返回 false）
void SetConsoleWindowVisible(bool visible);    // ShowWindow(GetConsoleWindow(), SW_SHOW / SW_HIDE)
```

隐藏靠 `ShowWindow`，**不是** `FreeConsole()`：

| 做法 | 后果 |
|---|---|
| `ShowWindow(SW_HIDE)` | 窗口藏起来，stdout 仍然连着，日志照写 |
| `FreeConsole()` | 断开控制台，之后 `printf` / `std::cout` 直接失败；再想显示得 `AllocConsole()` 重建并把 stdout 重绑到 `CONOUT$` |

只是"别看它"就够，所以选前者。

## 配置

`window.ini`：

```ini
[ui]
show_console=true
```

- 默认 `false`：启动就把控制台藏起来，界面看起来就是个纯 GUI 程序；用户点「命令行」按钮打开后写 `true`，下次启动保持
- 点按钮切换后立刻写盘（`QSettings::sync()`），下次启动 `main.cpp` 里读一次：

```cpp
qsc::base::SetConsoleWindowVisible(app_settings.ShowConsole());
```

## 数据流

```
主窗按钮点击
   │
   ▼
DeviceController::SetShowConsole(bool)
   ├── qsc::base::SetConsoleWindowVisible()   ← 立刻生效
   ├── AppSettings::SetShowConsole()          ← 写 window.ini
   ├── emit ShowConsoleChanged()              ← QML 按钮高亮跟着变
   └── SetStatus("命令行窗口已显示 / 已隐藏")
```

## 注意

- 切到 **GUI 子系统**（`QS_HIDE_CONSOLE=ON`）之后，按钮仍然存在但点了没反应，因为根本没有控制台窗口。真要在发布版也能开，得改成 `AllocConsole()` + 重绑 stdout/stderr，那条路没做
- 隐藏控制台后，如果程序卡住，用户看不到任何提示；日志文件仍然在 `Log/LOG_yyyy_MM_dd.log` 里，出问题看文件
