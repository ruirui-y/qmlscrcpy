# 输入层

把窗口里的鼠标键盘动作，翻成 scrcpy 的控制消息发回设备。

## 坐标换算

设备的触摸坐标是**视频帧坐标系像素 + 帧尺寸**，不是归一化值。所以第一步永远是换算。

```
拉满模式（keepAspect = false）：
    scale_x = 画布宽 / 帧宽          ← 一个帧像素在画布上占几个像素
    scale_y = 画布高 / 帧高
    帧坐标  = 画布坐标 / scale

等比模式（keepAspect = true）：
    scale   = min(scale_x, scale_y)  ← 取小的，保证塞得下
    offset  = (画布尺寸 - 帧尺寸 × scale) / 2   ← 居中留黑
    帧坐标  = (画布坐标 - offset) / scale
    点在 offset 之外 → 不命中，不发消息
```

代码：`libs/input/coordinate_mapper.h` / `.cpp`。

**这里踩过一个坑**：把"帧→画布"的缩放系数当成"画布→帧"用，等比模式下偏移全算反，是单测抓出来的（`QPoint(60,100)` vs 期望 `QPoint(90,100)`）。

## 触摸与滚轮

| 鼠标动作 | 触摸消息 | 说明 |
|---|---|---|
| 左键按下 | action=0 | 压力满值 0xFFFF，buttons 报主键 |
| 按住拖动 | action=2 | 只有按着才发，否则设备会当成悬停 |
| 左键抬起 | action=1 | 压力归零，buttons 清空 |
| 滚轮 | 独立消息 | 只在页面滚动，不产生触摸 |

固定值：

```
pointer_id = 0xFFFFFFFFFFFFFFFF   鼠标固定这个 id（多指才换）
button     = 1                    安卓 MOUSE_BUTTON_PRIMARY
```

滚轮方向：往上拨时协议里的 `v_scroll` 是负数（和安卓 `AXIS_VSCROLL` 一致）。协议层把归一化值除以 16 转定点，所以一格滚轮按 16 个单位送。

代码：`libs/input/touch_controller.h` / `.cpp`。

## 键盘

Qt 的按键要翻成安卓键码，三件事必须自己处理：

**① 键码映射**（`libs/input/keycode_table.cpp`）

字母、数字、F1~F12 在安卓键码里是连续区间，其余一个一个对：

```
A..Z  → 29..54      0..9 → 7..16      F1..F12 → 131..142
退格 67   删除 112   回车 66（主键盘和小键盘同一个）
Tab 61    空格 62    转义 111
Shift 59 / 60   Ctrl 113 / 114   Alt 58 / 61   Meta 117 / 118
```

没映射的键返回 0，调用方据此跳过，不会往设备发垃圾键码。

**② 重复次数要自己数**

Qt 只给 `isAutoRepeat` 一个布尔，安卓要的是"第几次重复"：

```
按下（非重复）→ repeat = 0
系统重复      → repeat = 上一次 + 1
抬起          → 计数清零，下次按下又从 0 开始
```

代码在 `KeyController` 里用 `QHash<int,int>` 记每个键的当前次数。

**③ 修饰键是位掩码**

安卓的 metaState 里，"通用位"和"左/右键专用位"都要置，设备两种读法都认：

| 修饰键 | 位 |
|---|---|
| Shift | `0x1` 通用 + `0x40` 左专用 |
| Ctrl | `0x1000` 通用 + `0x2000` 左专用 |
| Alt | `0x2` 通用 + `0x10` 左专用 |
| Meta | `0x10000` 通用 + `0x20000` 左专用 |

**按键消息布局**（`type` 只有 1 字节，没有长度字段）：

```
┌──────┬────────┬─────────┬────────┬───────────┐
│ 0    │ action │ keycode │ repeat │ metaState │
│ (1)  │  (1)   │  (4)    │  (4)   │   (4)     │
└──────┴────────┴─────────┴────────┴───────────┘
合计 14 字节
```

## 单测

`tests/tst_input.cpp`（5 条，坐标与触摸）：

- 拉满模式的换算
- 等比模式的命中/不命中
- 32 字节触摸消息的逐字段布局
- 抬起时清按键状态
- 一格滚轮打满偏转

`tests/tst_key.cpp`（7 条，键盘）：

- 字母数字区间、编辑键、修饰键
- 未映射键返回 0
- metaState 单键与组合
- 自动重复计数与抬起归零
- 14 字节按键消息布局
