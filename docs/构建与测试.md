## 环境变量

| 变量 | 作用 |
|---|---|
| `QS_ADB_PATH` | adb 可执行文件路径；不设就按 PATH → 同目录 找 |
| `QS_DEVICE_SERIAL` | 自动连这台设备，省得点按钮 |
| `QS_SCRCPY_SERVER` | 指定 scrcpy-server 路径，默认用 `third_party/scrcpy-server` |
| `QS_PERF` | `1` 时每秒打印链路耗时（等数据/解码/转换/上屏） |
| `QS_GRAB` | 启动 6 秒后截图到这个路径并退出，用于无人值守核对画面 |
| `QS_FORWARD` | 测试里强制走 forward 隧道 |
| `QS_LOG_LEVEL` | 临时覆盖 config.ini 里的日志级别（debug/info/warning/critical） |

其它有用的 Qt 变量：

| 变量 | 作用 |
|---|---|
| `QSG_INFO=1` | 打印渲染器信息（渲染线程、GL 版本、显卡） |
| `QSG_RENDERER_DEBUG=render` | 打印每帧渲染状态 |

## 踩过的环境坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 测试里堆损坏 `0xC0000374` | PATH 里第一个 Qt 是 5.14.2，和 5.15.2 编出来的混用 | 每个测试目标把 Qt DLL 拷到 exe 同目录（`qs_deploy_qt_runtime`） |
| `C1041 ... vc143.pdb` / `LNK1168` | 上一次的 exe 或 cl.exe 还活着 | 构建前先 `Stop-Process -Name QmlScrcpy` |
| 部署后没有 QML 模块 | 部署脚本没用 `--qmldir`，或 PATH 里的 windeployqt 是 5.14 | `cmake/DeployQt.cmake` 里把 Qt bin 放 PATH 最前面，并强制检查 `qml/*/qmldir` |
| QML 里 `Cannot assign to non-existent property "palette"` | `Window` 没有 palette（那是 Control 的属性） | 给每个控件单独配色，别在 Window 上设 |
| 读配置文件时 `QSettings::sync()` 卡几秒 | 每个尺寸变化事件都写盘 | 停在 400ms 后防抖写一次 |

## 代码约定速查

- 大括号一律独占一行（`if` / lambda / namespace 都一样）
- 行尾注释对齐第 97 列；块注释只写一行，最多两行，ASCII 图例外
- 单行上限 120 列，能一行写完的绝不折行
- 每个 `.cpp` 函数头顶一行中文注释；构造函数/析构函数不加
